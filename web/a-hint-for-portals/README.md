# A hint for Portals
**Author:** Lindsay Coudert
**Category:** Web

## Challenge Description
Thanks to Aperture Science you have been given the clearance to the files for a test chamber that has been designed by one of its employees. While the chamber appears to be completely solveable, well let's just say failure sometimes gets you the right way. Your goal is to go through the given HTML file and review the test chamber before it is built. Avoid directly opening the code.
