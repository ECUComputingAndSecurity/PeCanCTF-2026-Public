1) Open the provided pcapng file within Wireshark or a similar tool

2) On the top menu bar, navigate to [File] -> [export objects] -> [FTP-Data] then select the ODT on the newly opened window

3) After saving the ODT, open it and observe the Base64-encoded flag on the bottom-right side of the page

4) Use a tool like cyberchef to decode the Base64 into plain text

5) Observe the flag: Pecan{w1r3sh4rk15g04t3d}
