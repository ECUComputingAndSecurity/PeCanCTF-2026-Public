# Hamming Codez
**Author:** Cian McCormack
**Category:** Crypto

## Challenge Description
Hamming codes were invented in 1950 by Richard W. Hamming, a researcher at Bell Telephone Laboratories. He developed them to automatically detect and correct single-bit errors. Can you apply his ideas and recover the hidden message?

## Challenge Flag

## Hints
- The table order matters.
- The EC values act as codeword positions, not character values.
- Each EC represents a single bit flip, however the row it changes may be useful.
